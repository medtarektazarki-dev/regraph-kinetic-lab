# Brief intake

Collect only details that materially affect the result:

- Brand or product and the audience.
- Goal and one main message.
- Visual direction or example link.
- Destination/platform, dimensions, duration, frame rate.
- On-screen language and required copy.
- Available brand assets, footage, fonts, logo, music, or voice.
- Whether the user wants a finished render, preview, storyboard, or prompt.

Inspect supplied websites and local project material before asking for facts already available there. If a field is missing, use a context-appropriate assumption and state it briefly. Ask one concise question only when the answer would change the core creative direction, content, legal rights, or delivery requirements. Never invent brand claims or results.

Suggested short confirmation (only when needed): “I’ll make a 15-second vertical promo for Instagram, using your portfolio assets and a restrained editorial motion style. Is the 15-second length correct?”
