# Prompt-only deliverable

Use this mode when the user wants a prompt for another agent/model or the current environment cannot implement/render the video.

Deliver a reusable prompt containing:

- Verified brand and audience context, with source links where available.
- Video purpose, platform, duration, dimensions, frame rate, language, and audio direction.
- The selected reference URL and a short analysis of principles to adapt.
- One original concept and a beat-by-beat storyboard.
- Type, palette, composition, motion, transitions, assets, and constraints.
- A review checklist and exact deliverable expectations.

Do not present the prompt as a completed video or claim that a reference was inspected if it was not.
